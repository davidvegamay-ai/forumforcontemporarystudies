# forumforcontemporarystudies.org

Landing page and mailing-list signup for the Forum for Contemporary Studies.

- `index.html` – landing page with the signup form (Netlify Forms, form name `mailing-list`)
- `thanks/` – confirmation page shown after signup
- `style.css` – shared styles
- `netlify.toml` – security headers and www → bare-domain redirect

Hosted on Netlify; every push to `main` deploys.
